# Changelog — @lima-design/component-schemas

All notable changes to the Lima component schemas. Versioning policy: see
[README.md](README.md#two-versions).

## 0.1.0

Initial set. Format version 1.0.0.

- Components: ActionMenu, Banner, Button, Dialog, FormControl, InlineMessage,
  Select, Stack, TextInput
- Deprecated: the previous Dialog, as `dialog_deprecated`, imported from
  `@lima-design/react/deprecated`
- Format: `id`, `name`, `importPath`, `status`, `description`,
  `passthroughElement`, `props`, `subcomponents`, `types`
